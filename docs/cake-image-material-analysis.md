# 蛋糕素材视觉分析与提示词规则

## 素材位置

- 主目录：`materials/wife-moments-cake`
- 主要图片目录：
  - `materials/wife-moments-cake/JianyingPro Materials/训练lora`
  - `materials/wife-moments-cake/训练lora`

## 当前统计

- 按常规图片扩展名统计，有效图片文件约 `1260` 张，包含重复导出、副本和截图。
- 子agent 使用更宽松的 image-readable 口径扫描到约 `1292` 个可读素材，其中包含少量异常可读文件；产品结论不依赖精确数量。
- 主要格式是 JPG 和 PNG。
- 常见尺寸集中在 `1440x1080`、`1080x1440`、`2784x3712`、`3072x4096`、`1080x1080`，说明素材多为手机实拍、社媒图和截图。

## 视觉规律

1. 主体基本都是真实蛋糕店可制作的成品蛋糕，不是纯插画或纯概念图。
2. 构图以近景为主，蛋糕通常放在白色蛋糕托、蛋糕盒或干净桌面上。
3. 光线偏柔和自然光，背景多为浅色、白色、奶油色、店内陈列或拍摄棚。
4. 蛋糕结构以圆形、高筒圆柱、爱心形和少量方形为主。
5. 表面语言集中在奶油抹面、慕斯质感、裱花边、鲜果、糖珠、翻糖小摆件、手写字、祝福牌、年龄数字和节日插牌。
6. 用户情绪表达通常不是直接画人物，而是转译为配色、糖牌、文字、花朵、水果、宠物/玩偶简化摆件。
7. 平台调性应偏年轻、治愈、可分享，但不能过度幻想化，否则会降低真实蛋糕师接单可行性。
8. 子agent 抽样补充：真实素材中大量文字都很短，通常在糖牌、奶油字或蛋糕边缘；生图不应生成长句。
9. 子agent 抽样补充：朋友圈/小红书截图只能提供年轻社交语境，不应被模型生成成截图界面或带 UI 的图片。

## 已落入系统提示词的固定规则

- 只生成蛋糕：用户输入任何主题，都必须转译为真实可食用蛋糕设计。
- 文生图递进：先形状和层高，再奶油/慕斯基底和主色，再主视觉装饰，再辅助装饰，最后统一光线、背景和可制作结构。
- 微调递进：先保留原图蛋糕结构、角度、主色和主题，再按用户要求做局部升级，不默认重画成另一款蛋糕。
- 负面约束：避免非蛋糕主体、截图界面、社交媒体 UI、海报、插画感过重、玩具模型、品牌商标、版权角色、二维码、联系方式、价格标签、巨大悬浮结构、多人入镜、手部遮挡、多个蛋糕抢主体、脏乱桌面和破损/发霉/恐怖元素。
